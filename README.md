# Used Car Price Prediction & Analysis

## 📌 Project Overview
This project analyzes a dataset of used cars from CarDekho to understand the factors influencing the resale value of vehicles. The goal is to perform Exploratory Data Analysis (EDA) and build a model that can accurately estimate the selling price of a car based on its features.

## 📊 Dataset Description
The dataset contains information on several thousand used cars with the following features:
- **Car Name & Brand**: Model and manufacturer.[cite: 1]
- **Vehicle Age**: Years since manufacture.[cite: 1]
- **Distance Driven**: Total kilometers logged.[cite: 1]
- **Fuel Type**: Petrol, Diesel, CNG, or LPG.[cite: 1]
- **Transmission**: Manual vs. Automatic.[cite: 1]
- **Selling Price**: The target variable (Target).[cite: 1]

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Platform:** Google Colab / Jupyter Notebook

## 📈 Key Insights (Sample)
- **Depreciation:** Vehicle age is the strongest predictor of price drop, with luxury brands (BMW, Mercedes) seeing higher absolute depreciation.[cite: 1]
- **Fuel Impact:** Diesel cars generally command a higher resale price compared to petrol variants of the same model.[cite: 1]
- **Mileage:** Cars with lower "km_driven" maintain significantly higher value retention.[cite: 1]
